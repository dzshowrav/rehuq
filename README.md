# Rehuq — Single-Vendor E-Commerce Platform

A Daraz-inspired **single-vendor** e-commerce store. **Laravel 11** powers a complete REST API (storefront + admin), built to be consumed by **React** frontends — with a rich, responsive design system planned for desktop, tablet and mobile (PWA-ready).

> Status: Laravel backend + admin API complete and seeded. React storefront/admin UIs are the next milestone.

---

## Stack

| Layer | Technology |
|---|---|
| Backend | Laravel 11 (PHP 8.2+), Sanctum token auth, Eloquent ORM, SQLite (MySQL-ready) |
| API | REST + JSON, public + auth + admin scopes |
| Frontend (next) | React 18 + Vite, responsive PC / tablet / mobile layouts, PWA |
| Media | SVG placeholders generated by the API, uploads served from `/storage/...` |

## What's inside

- **Storefront API** — products, categories (multi-level tree), banners, pages, search, filters, sorting, flash sales, featured products, brands, reviews/ratings, site config
- **Cart & checkout** — guest carts (session token), auth merge, coupons, shipping methods, payment methods (COD etc.), tax, order placement with stock control, order numbers
- **Account** — register/login (Sanctum tokens), profile, addresses, order history + tracking + cancellation, wishlist, product reviews
- **Admin API (full backend control)** — dashboard analytics (revenue/charts/top products), products CRUD + images + flash sale + featured, categories, orders (status/payment/tracking, stock restore on cancel), coupons, banners, reviews moderation, users, pages, shipping & payment methods, **site settings** (store name, logo, colors, hero, announcements, features, contact/socials, SEO meta, currency, tax, free-shipping threshold), file uploads (binary + base64)
- **Demo data** — 100 products across 10 top-level categories with 60+ subcategories, banners, coupons, pages, reviews, and demo users

## Quick start (real machine)

```bash
cd backend
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve          # API on http://localhost:8000
```

The API base is `http://localhost:8000/api`. Explore it in a browser or with curl.

## API overview

```
GET    /api/site-config                 store-wide settings (name, colors, shipping, payment…)
GET    /api/categories                  category tree
GET    /api/products?category=&q=&sort=&min_price=&brand=…
GET    /api/products/featured | /flash-sale | /brands
GET    /api/products/{slug}             detail + reviews + related
GET    /api/banners?position=home_hero
GET    /api/pages/{slug}
POST   /api/auth/register | /login | /admin/login
POST   /api/cart/items                  cart endpoints (guest via X-Session-Token header)
POST   /api/checkout                    place order
POST   /api/admin/products              admin CRUD (Bearer admin token) — all admin routes under /api/admin
```

Auth: `Authorization: Bearer <token>` (customer or admin). Admin routes additionally require the user to have `is_admin = true`.

## Sandbox preview

The `preview/` folder contains a Node harness that runs the **entire Laravel backend through PHP.wasm** — no local PHP install needed:

```bash
cd preview
npm install
ln -s node_modules/@php-wasm/node-8-3/asyncify/8_3_32 ./8_3_32   # runtime symlink
node server.mjs 8080          # add --reset to wipe & reseed the DB
```

On first boot it runs `composer dump-autoload`, `php artisan migrate` and `php artisan db:seed` automatically.
